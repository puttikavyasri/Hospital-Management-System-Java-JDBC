# Hospital Management System

## Overview

Hospital Management System is a Java-based console application developed using JDBC and MySQL. It helps manage patients, doctors, and appointments efficiently.

## Technologies Used

* Java
* JDBC
* MySQL
* Eclipse IDE

## Features

* Add Patient
* View Patients
* View Doctors
* Book Appointments
* Database Connectivity using JDBC

## Database Tables

1. Patients
2. Doctors
3. Appointments

## Project Flow

1. Register Patient
2. View Doctors
3. Select Doctor
4. Book Appointment
5. Store Data in MySQL Database

## Learning Outcomes

* JDBC Connectivity
* SQL Queries
* PreparedStatement
* Database Design
* Java OOP Concepts
